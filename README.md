# Налаштування ігрового ПК після переустановки Windows

Ryzen 7 7800X3D · RTX 5070 Solid · B650 AORUS ELITE AX V2 · DDR5-6000 CL30 · MSI MAG 274QP

Усе, що налаштовувалось (від BIOS до Valorant), зібране в одній папці.

| Файл | Що це |
|---|---|
| `guide.html` | Довідник-чекліст по етапах: BIOS, Windows, драйвери, NVIDIA, андервольт, монітор, Valorant, миша, клавіатура, SSD, тести. Галочки зберігаються в браузері. Відкривається подвійним кліком. |
| `START.cmd` | Запуск програми налаштування (просить права адміністратора). |
| `setup.ps1` | Сама програма: перевірка стану, налаштування Windows, установка програм. |

## Як користуватись

1. Скачай папку (Code → Download ZIP) на флешку, ще до переустановки.
2. Після установки Windows відкрий `guide.html` і йди по етапах зверху вниз.
3. На етапі «Програма налаштування» запусти `START.cmd`.

## Меню програми

```
1  Перевірити все (нічого не змінює)
2  Застосувати налаштування Windows (питає перед кожним)
3  Встановити програми (winget)
4  Відкрити офіційні сайти (драйвери, Afterburner, Magician, миша, клава)
5  Створити точку відновлення
6  Відкрити довідник (guide.html)
```

**Пункт 2** змінює тільки те, що й так міняється в «Параметрах» Windows:
швидкість миші 6/11, «Підвищена точність» вимк., меню завантаження вимк. (таймаут 3 с),
Game Mode, фоновий запис Game Bar вимк., HAGS, оптимізації для віконних ігор, VRR,
темна тема, автоприховування панелі завдань, вимкнення екрана через 5 хв,
план живлення «Збалансований». Перед кожною зміною питає, старі значення пише в `logs\`.

**Пункт 1** додатково перевіряє: RAM на 6000 MT/s (EXPO), Resizable BAR, монітор 2560×1440 @ 240 Гц,
драйвери NVIDIA і AMD Chipset, Secure Boot, fTPM, Vanguard, помилки WHEA за 30 днів, стан дисків, автозапуск.

**Пункт 3** ставить через winget: OCCT, BCUninstaller, Valorant (EU); за бажанням Chrome, DDU, LatencyMon.
MSI Afterburner і Samsung Magician ставляться вручну з офіційних сайтів (пункт 4): Afterburner у winget
качається з дзеркала, а не з msi.com, Magician у winget немає.

## Чого програма не робить

Твіки реєстру «для FPS», вимкнення служб, Defender, Memory Integrity, C-states, файлу підкачки,
ручні напруги, Ultimate Performance. BIOS програмно не змінюється: значення є в довіднику.
